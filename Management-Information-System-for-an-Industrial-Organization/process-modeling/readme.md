# Process Modeling

This folder contains the Visual Paradigm .vpp models associated with the industrial organization's management information system.

- warehouse-management.vpp — warehouse management
- energy-management.vpp — energy management
- production-planning-and-control.vpp — production planning and control
- financial-accounting.vpp — financial accounting
- product-production.vpp — product production
- human-resources.vpp — human resources
- maintenance-management.vpp — maintenance and repairs
- quality-control.vpp — quality control

The filenames have been translated into descriptive English names; the model contents have not been altered. Open the files in compatible Visual Paradigm software.
