# Database

## Main script

Use manufacturing-operations-database.sql as the primary script to review. It contains the database tables and sample data, followed by SELECT statements for inspecting the tables.

## Reference export

manufacturing-operations-schema-export.sql is a SQL Server-generated schema export for a database named EX3. It is retained for reference and is not intended to be run alongside the main script without first comparing the schemas. It may include local SQL Server file paths.

## Before running

The scripts have not been certified as error-free. Inspect table-definition syntax, table creation order, foreign-key consistency, and sample data before executing in a test environment. The schema export and main script are alternative artifacts, not two steps in one installation process.
