# Business Analytics Portfolio

A collection of academic projects exploring how business processes, structured data, and quantitative decision methods can support operational understanding and business decision-making.

This repository brings together work in **business process modeling, relational database design, management reporting, financial-ratio analysis, and multi-criteria decision-making**. Each project includes its own README with more detail about the scope, artifacts, methodology, and limitations.

## Projects

### 1. Industrial Organization Management Information System

**Focus:** Business process modeling · SQL Server · Relational database design · Power BI

[Open project folder](./Management-Information-System-for-an-Industrial-Organization) · [Read project README](./Management-Information-System-for-an-Industrial-Organization/README.md)

This project represents operational and administrative workflows for an industrial organization and connects process documentation with a relational data model and management reporting.

**What it includes**
- Eight process models covering energy management, maintenance, production planning and production, quality control, human resources, financial accounting, and warehouse management.
- A SQL Server database script with table definitions, sample records, and queries for inspecting the data.
- An editable Power BI report and a PDF snapshot for reviewing management-oriented views.

**Skills demonstrated**
- Business process analysis and workflow documentation
- Relational data modeling and SQL
- Translating operational concepts into structured data
- Dashboard/report interpretation and management information design

### 2. Financial Performance Evaluation Using TOPSIS

**Focus:** Financial ratio analysis · Excel · Multi-criteria decision-making (MCDM) · TOPSIS

[Open project folder](./Financial-Performance-Evaluation-TOPSIS) · [Read project README](./Financial-Performance-Evaluation-TOPSIS/readme.md) · [Open Excel workbook](./Financial-Performance-Evaluation-TOPSIS/TOPSIS-Financial-Performance-Analysis.xlsx)

This academic project applies the Technique for Order Preference by Similarity to Ideal Solution (TOPSIS) to compare companies using financial indicators. The report describes two case studies: 13 Turkish technology companies evaluated using 10 financial ratios, and 12 Iranian oil, refining, and petrochemical companies evaluated using eight indicators.

**What it explores**
- Financial-ratio-based company comparison
- Decision-matrix normalization and criterion weighting
- Positive and negative ideal solutions, distance calculations, and relative-closeness scores
- Comparison of TOPSIS rankings with the report's discussion of market value and fundamental analysis

**Skills demonstrated**
- Financial ratio interpretation
- Excel-based analytical modeling
- TOPSIS ranking and decision analysis
- Critical interpretation of model assumptions and limitations
